# Telegram-бот группового чата

Бот для беседы: дни рождения, сходки с опросом и напоминанием, погода на локации.
Данные хранятся в локальных JSON-файлах, БД не нужна.

## Возможности

- **Дни рождения** — список по месяцам, поздравление в 09:00, добавление и удаление.
- **Сходки** — официальный анонс с фото и картой, закрепление, публичный опрос
  «Ты идёшь?», напоминание за 2 часа с упоминанием всех участников.
- **Погода** — прогноз на локацию, дату и время через Open-Meteo (без ключа).
- **Админ-панель в личных сообщениях** — правка дней рождения, локаций, сходки
  и папки с фото. Доступна только владельцу из `ADMIN_USER_ID`.

## Структура

```
main.py                 точка входа
requirements.txt        зависимости
config/locations.json   локации
config/photos/          фотографии локаций из репозитория
data/                   состояние бота (создаётся автоматически)
data/photos/            фото, загруженные через бота
tests/                  тесты
```

## Переменные окружения

Значения задаются в `.env` локально или в панели Bothost в разделе
«Переменные окружения». Файл `.env` в репозиторий не попадает.

| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `BOT_TOKEN` | да | — | токен от [@BotFather](https://t.me/BotFather) |
| `GROUP_CHAT_ID` | нет | последний чат | id группы; без него берётся последний чат, где писали боту |
| `ADMIN_USER_ID` | нет | — | ваш Telegram id — открывает админ-панель в личке |
| `TIMEZONE` | нет | `Europe/Moscow` | часовой пояс для задач и прогноза |
| `DAILY_HOUR` | нет | `9` | час ежедневной сводки |
| `DAILY_MINUTE` | нет | `0` | минута ежедневной сводки |
| `DELETE_SERVICE_MESSAGES` | нет | `true` | удалять служебные сообщения команд |

Свой id можно узнать командой `/chatid` в группе или у [@userinfobot](https://t.me/userinfobot).

## Запуск локально

```bash
pip install -r requirements.txt
python main.py
```

Проверка конфигурации без запуска бота:

```bash
python main.py --check
```

На Windows удобнее `start_bot.bat`.

## Админ-панель

Напишите боту в личные сообщения `/start` — откроется панель:

- **🎂 Дни рождения** — список, добавление, удаление по одной записи.
- **📍 Локации** — список, добавление мастером из 8 шагов, удаление,
  привязка фото.
- **🖼 Фото** — список с пометкой, к какой локации привязан файл, загрузка и
  удаление. Имя файла задаётся подписью к фото или отдельным сообщением —
  именно оно указывается у локации. Новые файлы пишутся в `data/photos`, чтобы
  не пропадать при обновлении из Git.
- **📢 Сходка** — просмотр, изменение даты и времени (напоминание и закрытие
  опроса пересоздаются), очистка `meetup.json`.

В группе всё работает как раньше: панель отвечает только владельцу и только
в личных сообщениях.

## Развёртывание на Bothost

1. Загрузите код в репозиторий GitHub.
2. В Bothost создайте бота: платформа Telegram, библиотека `python-telegram-bot`.
3. Укажите Git URL, ветку `main`, главный файл `main.py`.
4. Добавьте переменные окружения: `BOT_TOKEN`, `GROUP_CHAT_ID`, `ADMIN_USER_ID`.
5. Запустите деплой и смотрите логи.

Папка `data/` на Bothost сохраняется между обновлениями — состояние бота и
загруженные фото не потеряются при повторном деплое.
